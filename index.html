Самый частый язык программирования

Простота. Мощь. Элегантность.

Python — это язык программирования, способ дать компьютеру точные, повторяемые инструкции. Он доминирует в науке о данных и искусственном интеллекте по двум причинам: читается почти как английский, и огромное сообщество создало на этом основе бесплатные инструменты — для таблиц данных, для графиков, для машинного обучения. Когда исследователи анализируют данные опросов, когда больница строит модель риска, когда обучается современная система искусственного интеллекта — Python почти наверняка участвовал..

Фундамент языка

01

Блокнот Jupyter

Текстовые ячейки — заметки и объяснения. Кодовые ячейки — настоящий Python, который можно запускать..

# Всё есть объект
name = "Python"
version = 3.12
is_awesome = True
02

Переменные — маркированные поля для ваших данных

Прежде чем компьютер сможет работать с определённым значением, ему нужно где-то её хранить. Переменная — это имя, прикреплённое к значению — представьте её как маркированную коробку:.

03

Структуры данных

Встроенные списки, словари и множества оптимизированы для эффективной работы из коробки.

# Словари (Key-Value)
stack = {
  "web": "Django",
  "ai": "PyTorch"
}
04

Функции

Первоклассные объекты: передавайте функции как аргументы, возвращайте их и создавайте лямбды.

def greet(user: str) -> str:
  return f"Привет, {user}!"

square = lambda x: x ** 2
05

ООП и Классы

Элегантное объектно-ориентированное программирование с магическими методами и наследованием.

class Developer:
  def __init__(self, lang):
    self.lang = lang

dev = Developer("Python")
